# AssetVerse Client

## 📌 Project Overview

**AssetVerse Client** is a modern asset management web application frontend built with **React, Vite, and TailwindCSS**. The platform allows organizations to manage assets efficiently, visualize data with charts, generate reports, and handle authentication using Firebase.

The application focuses on providing a **responsive, interactive, and user-friendly dashboard experience** for both administrators and employees.

## 🚀 Key Features

* 🔐 Secure authentication using **Firebase**
* 📊 Interactive charts and analytics using **Recharts**
* 📄 Generate downloadable reports with **jsPDF** and **jsPDF-Autotable**
* 📑 Advanced form management with **React Hook Form**
* ⚡ Data fetching and caching using **React Query**
* 🎨 Fully responsive UI built with **TailwindCSS** and **DaisyUI**
* ✨ Smooth animations using **Framer Motion** and **Lottie**
* 🔔 Beautiful alert notifications using **SweetAlert2**
* 🖨 Print functionality using **react-to-print**
* 📍 Map integration with **Leaflet** and **React Leaflet**
* 🎠 Carousel/slider UI using **Swiper**

## ⚙️ Installation & Setup

Clone the repository

```
git clone https://github.com/your-username/assetverse-client.git
```

Go to project folder

```
cd assetverse-client
```

Install dependencies

```
npm install
```

Run development server

```
npm run dev
```

Build for production

```
npm run build
```

Preview production build

```
npm run preview
```
